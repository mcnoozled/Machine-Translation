# Machine-Translation
**Лабораторная работа №1**
Выполнил: Жильцов Даниил Александрович
Группа: ИНФА-221
Вариант: 3. Медицина: кардиология и кардиохирургия

**Цель**

Освоить программную обработку стандартов обмена терминологическими данными, научиться искать нечёткие совпадения (Fuzzy Match), выполнять автоматическую подстановку терминов из глоссария и выгружать результаты в формате, совместимом с CAT-системой Smartcat.

**Задачи**
  1. Проверить и разобрать XML-структуру терминологической базы TBX.
  2. Извлечь параллельные сегменты из памяти переводов TMX.
  3. Реализовать метрику сходства строк и поиск нечётких совпадений с ранжированием.
  4. Выполнить автоматическую подстановку терминов глоссария в исходный текст.
  5. Подготовить экспорт данных для импорта в Smartcat.

**Исходные данные**

TBX-глоссарий: 100 терминов EN–RU по кардиологии и кардиохирургии (variant_03.tbx)
TMX-память: 100 параллельных предложений EN–RU (variant_03.tmx)
Предметная область:	Медицина: кардиология и кардиохирургия
Проверка терминов:	Кардиология по Хёрсту

**Использованные источники**

Fuster V., Harrington R. A., Narula J., Eapen Z. J. (Eds.). Hurst’s The Heart. 14th ed., 50th anniversary ed. In 2 vols. New York: McGraw-Hill Education, 2017. — ISBN 978-0-07-184311-9
(использован только этот источник, т.к. он содержит 2613 страниц в оригинале, в нем очень большое количество терминов по предметной области)

**Полученные результаты**

Валидация TBX прошла успешно: структура корректна, ошибок не обнаружено.
Из TBX извлечено 100 терминов.
Из TMX извлечено 100 единиц перевода.
